# Ryan Tan Portfolio

A personal portfolio for Ryan Tan, a senior full-stack engineer based in Singapore.

[Live website](https://ryantan.vercel.app/) | [GitHub](https://github.com/ryantanio) | [Email](mailto:ryantan.htn@gmail.com)

![Ryan Tan portfolio first screen](docs/portfolio-home.png)

The site presents Ryan's work across healthcare, government, finance, insurance, education, and consumer products. It is written in a quieter, more human tone than a typical template portfolio, with project notes grounded in public sources and resume context.

## What Is Inside

- A full-screen intro section with Ryan's positioning as a senior full-stack engineer
- An about section focused on the kind of product work he has done
- A career timeline inspired by Brittany Chiang's v2 portfolio layout
- Selected project work with screenshots, public links, and contribution notes
- A clear contact section with email, GitHub, and resume actions

## Selected Projects

The project section focuses on five strong examples from Ryan's experience:

| Project | Context |

| SCO Digital Archives | Public archive website for the Singapore Chinese Orchestra |
| Price Kaki | Consumer price comparison app for groceries, essentials, and hawker food |

## Tech Stack

Built with Vite, React, TypeScript, Tailwind CSS, and Lucide icons. The site uses local fonts and local image assets, so it can be deployed as a static frontend with no backend or environment variables.

## Run Locally

```sh
npm ci
npm run dev
```

In PowerShell, use `npm.cmd` if `npm.ps1` is blocked by the execution policy.

```sh
npm.cmd run build
npm.cmd test
```
