## Copy approach

The portfolio uses American English in its narrative text, while preserving official names such as Singapore Safety Driving Centre. Each project has its own heading and short account of the work, rather than the same two contribution bullets. Employment summaries explain the progression from application and integration work at Vinova to broader backend/cloud responsibility at OriginallyUs and development plus production support at Masimo.

Specificity stays within the supplied experience: community data and AI-assisted moderation for Price Kaki; web pages and content integration for SCO; student-facing screens and backend connections for SSDC; website/portal interfaces for ITEES; application updates and API integration for FWD; web services, databases, AWS deployments, and release fixes for Masimo. These restate the existing record without adding feature ownership or performance claims. For CPFV and Singa, where personal task detail is limited, the new technical detail is clearly product context. Per-project scope labels describe the product; named frameworks remain in the career and skills sections where the resume supports them.

The HTML resume and downloadable PDF use the same terminology. The source notes retain the evidence and chronology qualifications even where the public-facing text has been shortened.
